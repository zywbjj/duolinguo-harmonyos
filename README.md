# Duolinguo for HarmonyOS

非官方个人项目：使用 ArkWeb 加载 Duolingo 官方网页，结合 ArkUI 原生导航、系统主题和离线英语语音识别。与 Duolingo 官方无关联。

当前版本：1.0.11。课程、功能和账号状态由 Duolingo 服务提供；原生课程客户端尚未完成。

使用 DevEco Studio 打开本目录构建，所需 HarmonyOS SDK 版本见 build-profile.json5。构建结果为未签名 HAP，需自行配置签名后安装。

第三方组件及模型许可证见 THIRD_PARTY_NOTICES.md 和 entry/src/main/resources/rawfile/voice/NOTICE.txt。
